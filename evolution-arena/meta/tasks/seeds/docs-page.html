Quickstart

Quill is a JavaScript SDK for storing and serving files.

1. Install

npm install @quill/sdk

2. Create a client

import { Quill } from '@quill/sdk';
const quill = new Quill({ projectId: 'YOUR_PROJECT_ID' });

3. Upload a file

const file = await quill.upload(input.files[0]);
console.log(file.url);

Next: read the Auth guide to restrict who can upload.
